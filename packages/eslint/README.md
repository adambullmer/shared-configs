# eslint

> Sharable config for [eslint](https://eslint.org/)

## Using the config

Install with your preferred package manager as a devDependency.
Then export this package from your preferred [eslint config file location](https://eslint.org/docs/latest/use/configure/configuration-files#configuration-file).
For simplicity, the below example assumes your config file is `eslint.config.mjs`.

```sh
echo "import eslintConfigAb from \"@adambullmer/eslint-config\";\nexport default [...eslintConfigAb];" > eslint.config.mjs
```
