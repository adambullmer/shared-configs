# semantic-release

> Sharable config for [semantic-release](https://semantic-release.gitbook.io/semantic-release)

## Using the config

Install with your preferred package manager as a devDependency.
Then export this package from your preferred [semantic-release config file location](https://semantic-release.gitbook.io/semantic-release/usage/configuration#extends).
For simplicity, the below example assumes your config file is `release.config.mjs`.

```sh
echo 'export { config as default } from "@adambullmer/semantic-release-config";' > release.config.mjs
```
