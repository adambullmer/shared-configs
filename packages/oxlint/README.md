# oxlint

> Sharable config for [oxlint](https://oxc.rs/docs/guide/usage/linter.html)

## Using the config

Install with your preferred package manager as a devDependency.
Then add this package to the [.oxlintrc.json](https://oxc.rs/docs/guide/usage/linter/config-file-reference.html) file `extends` array.

```sh
echo '{\n  "extends": ["@adambullmer/oxlint-config"]\n}' > .oxlintrc.json
```
